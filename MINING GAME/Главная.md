# MINING GAME

Майнинг-симулятор в Roblox Studio.

## Системы
- [[Система шахты]] — Блоки, урон, вместимость, радиус атаки. Шахта — деталь `workspace.Mine.MineArea`.
- [[Уровни и опыт]] — Опыт за каждый блок (`xp` в [[MiningShared]]), формула `50 * level^1.6`, кап 35, полоска уровня, слоты по уровню, эффект level up и танец шара ([[CapacityOrb]]).
- [[Кирка]] — Удар только по блоку под курсором, кирка за спину через 3 с.
- [[Эффекты]] — Тряска, осколки, пыль, полоска HP, цифры урона, Slash и Break при разрушении.
- [[Интерфейс]] — HUD, шар вместимости, всплывашки над головой.
- [[Персонаж]] — Анимация, шаги, столкновения.
- [[Таблички]] — Табличка с уровнем и ником над головой, прячется в шахте.
- [[Погода]] — Default / Sunny / Rain / Rainstorm, плавная смена Lighting.
- [[Графика]] — Настройки Lighting.
