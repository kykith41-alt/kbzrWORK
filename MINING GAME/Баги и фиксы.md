# Баги и фиксы

| Проблема | Причина | Исправление |
|---|---|---|
| GUI шара растёт при отдалении камеры | размер в пикселях | размер в стадах — [[CapacityOrb]] |
| `Unable to assign property Font` | `Font.new` в свойство `Font` | писать в `FontFace` — [[MiningHUD]] |
| `cannot write 'Technology'` | Command Bar не может менять | ставить вручную — [[GraphicsCommandBar]] |
| Нет цифры урона на добивающем ударе | `BlockHit` не приходит на последнем ударе | показ при `BlockBroken` — [[MiningEffects]] |
| `SoundId ... got table` | `Collect` стал списком | `PlaySound` принимает список — [[MiningShared]] |
| Погода резко «бамкает» цветом | мои слои RainMood / WeatherFade | убраны — [[WeatherClient]] |
| Rainy не появлялся | точное имя папки | поиск по подстроке «rain» — [[WeatherClient]] |
| Персонажа толкает при копании | осколки и кирка с коллизией | группы столкновений — [[CollisionSetup]] |
| Отбрасывает назад при упоре в блок | наклон тела в анимации удара | верх тела без коллизии — [[CollisionSetup]] |
| Провал сквозь блоки | коллизия выключена у всего тела | без коллизии только верх — [[CollisionSetup]] |
| Шаги слишком частые | таймер вместо анимации | событие `Footstep` — [[CharacterAnimator]], [[FootstepSounds]] |
| Три звука шага сразу | стандартные шаги Roblox + старый скрипт | пустой `RbxCharacterSounds`, `MIN_GAP` — [[FootstepSounds]] |
| Звук level up с задержкой | звук создавался на сервере и грузился при первом проигрывании | клиент + предзагрузка — [[LevelUpFX]] |
